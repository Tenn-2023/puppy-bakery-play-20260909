## 本地运行

运行 `python3 -m http.server 8099 --directory docs`，打开 `http://localhost:8099`。不要直接双击 HTML。

## 发布与校验

GitHub Pages 从 main 的 /docs 发布。Godot 4.7.2 Compatibility Web 单线程；资源包按 48 MiB 分块加载并校验 SHA-256。docs/release.json 记录发行版本与分块，FILES.json 校验网页文件，BUILD.json 与 MODELS.json 追溯资源。本仓库只放当前网页运行文件和许可，不包含原工程、建模试样、缓存或测试存档。
