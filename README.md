# 小狗店长的面包屋 · 2026.09.13 · C 界面与教学试玩

本仓库只保留本次网页运行文件、校验清单和 Pages 发布目录，不包含旧导出、建模试样、测试存档、缓存或原始工程。

当前版本包含拱顶与整墙彩绘湖畔餐厅（庭院侧楼梯、前低后高），以及已接入的新后厨和手动操作。游戏仍在制作中；部分食谱使用兼容操作面板，角色工作动作和材质仍在调整。桌面浏览器试玩验证不等于实体手机全流程验收。

首次进入会清理该游戏旧试玩存档，从选店长开始；此后保留进度。入口“清除进度 · 从头开始”可重新开局。不会清理其他网站数据。

本次采用 C 界面：图标快捷入口、配方册、原料超市、当前动作提示、固定右下角操作区。开局三张固定配方自动翻开；第一炉牛奶小餐包按步骤教学，搅拌自动进行，揉面垫累计长按6秒，松手暂停。完成备货后由玩家开始营业，首位顾客耐心等待，完成第一单后开放其他配方和经营。问号打开游戏内搜索手册与本地动画示意，查阅时暂停游戏。

五位具备完整手臂骨骼的店长使用现有端碗、切分、装盘等动画；当前腊肠犬原模型仅有单段手臂骨骼，采用兼容操作与工作动作，可完成相同配方流程，尚未补全同等级搬运动画。既有存档保留；已在制作中的批次沿用原步骤。实体手机全流程和独立新玩家易用性验收仍需实机反馈。

## 本地试玩

在本文件所在目录运行 `python3 -m http.server 8099 --directory docs`，打开 `http://localhost:8099`。不要直接双击 HTML 文件。

## 部署

GitHub Pages 从 `main` 分支的 `/docs` 目录发布。资源包以校验过的分块文件加载，每块小于 GitHub 单文件限制。`docs/release.json` 记录大小和 SHA-256，`BUILD.json` 记录正式资源校验值。

Godot 4.7.2 Compatibility，Web 单线程。游戏与美术资源未授予通用开源授权；Godot 及字体使用各自许可证，见 `docs/licenses/`。
